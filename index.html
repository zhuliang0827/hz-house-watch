09评分口径与分档规则

把打分规则写全,让排序可解释、可推翻。

维度默认权重规则
地铁可达18% 步行 ≤500m=100 / ≤800m=85 / ≤1200m=65 / ≤2000m=40 / 更远=20;无数据=50
租售比22% ≥3.0%=100 / ≥2.8%=90 / ≥2.5%=72 / ≥2.2%=50 / 更低=28;无数据=50
楼龄14%≤10 年=100 / ≤20 年=82 / ≤30 年=52 / 更老=22
面积适配14% 按家庭结构取区间(不再是固定 50–85㎡):两口/单身 45–75㎡、三口 70–100㎡、 三口+老人 95–135㎡ → 区间内=100 / 相邻=78 / 偏远=52 / 过远=30。区间可在页面上切换。
单价分位17% 按当期样本池的分位:≤P10=100 / ≤P25=86 / ≤P50=70 / ≤P75=52 / 更高=34
供给密度15% 同小区在本期样本中的在售套数:≤1 套=100 / ≤3=82 / ≤6=62 / 更多=40。 这是本看板唯一的流动性因子,方向是「竞品越少越有利于将来转手」。
学区0%(可调) 有贝壳学区标注=100,无=40。默认权重为 0 —— 学区需求因人而异, 默认替你加权等于替你做了决定。需要时把滑杆拉起来。
电梯不计分 贝壳未直接提供,由总层数推断并在列中标注,未核实
总分怎么算:总分 = Σ(因子分 × 权重) ÷ Σ权重。权重之和不必等于 100, 归一化后自动缩放,因此「把学区从 0 拉到 20」不会让所有分数整体虚高,只会重新分配相对重要性。
等级怎么切:排序后按池内分位切档 —— S = 前 10%,A = 10–35%,B = 35–70%,C = 后 30%。 这样做的好处是:换权重、换筛选条件时,等级自动重算,不会出现「S 级门槛是 78 分」这种 依赖当时样本分布的隐形假设。代价是:S 级不等于好房子,只等于「在当前偏好下排在前 10%」。
已知的评分缺陷(诚实披露):① 租售比是静态当下值,不反映租金与价格的变化方向; ② 除供给密度外,没有真正的「板块景气度」因子 —— 因为本看板拿不到板块级成交数据; ③ 面积适配与学区是按你的偏好评分,不是按市场认可度评分,对转手价值的解释力有限。

→ 影响:无法计算真实去化速度。修法:交叉网签数据,或对停售房源做人工抽样回访。
